# Black Cat Burger

A mystical, late-night burger experience website featuring a black cat-themed restaurant that serves dream-inspired burgers and coffee.

## 🌙 Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Interactive Navigation**: Smooth scrolling and dynamic header behavior
- **Menu System**: Tabbed menu interface for burgers, sides, and drinks
- **Location Pages**: Multiple store locations with embedded maps
- **Dark Theme**: Elegant dark theme with organic animations
- **Accessibility**: ARIA labels and keyboard navigation support

## 🚀 Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. No build process required - it's pure HTML/CSS/JavaScript

## 🛠 Technologies Used

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Modern CSS with custom properties, animations, and responsive design
- **Vanilla JavaScript**: No frameworks required, pure JS for interactions
- **Google Fonts**: Space Grotesk, Noto Sans JP, and Oswald
- **Font Awesome**: Icon library

## 🎨 Design Highlights

- **Organic Animations**: Subtle floating and twinkling effects
- **Glass Morphism**: Modern glass-like panels with backdrop filters
- **Smooth Scrolling**: Parallax effects and scroll-triggered animations
- **Interactive Elements**: Hover states, focus management, and micro-interactions
